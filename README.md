# Comparative and Functional Analysis of Short Introns

This repository contains the data-processing pipelines and
figure-generation scripts used to characterize short introns and
investigate their sequence features, splicing regulation, evolutionary
conservation, and cross-species properties.

The repository is organized into three main components:

1.  `data_processing/` – generation and preprocessing of intron datasets
2.  `orthologous_introns/` – identification of orthologous introns and
    assignment of evolutionary age
3.  `figures/` – scripts used to generate the figures in the manuscript
