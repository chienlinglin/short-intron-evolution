# Intron dataset preparation

This directory contains scripts used to generate and process intron/gene annotations for human, yeast, plants, and vertebrates. 

## Scripts

### `getIntrons_GRCh38_gtf.R`

Generates the primary human intron annotation from the **GENCODE v38 GRCh38 GTF**.

The script:

-   extracts exon coordinates from the GENCODE annotation;

-   derives transcript-level intron coordinates;

-   retains transcripts without introns for gene-level classification;

-   calculates intron length and GC content;

-   annotates canonical GT-AG splice sites;

-   classifies short introns as:

    -   GC-rich: GC content ≥ 0.45
    -   AT-rich: GC content \< 0.45

-   generates gene-level intron classifications.

Short introns are defined as **30–100 nt**, whereas introns \>100 nt are considered long introns.

Major outputs include:

``` text
exon_df_GRCh38.rds
intron_df_full_GRCh38.rds
intron_df_GC_GRCh38.rds
intron_df_GC_GRCh38.csv
all_gene_GRCh38.rds
all_gene_GRCh38.csv
```

The generated human intron annotation serves as the reference dataset for subsequent human short-intron analyses.

### `human_introns_examined.R`

Generates a non-redundant set of human introns for downstream analyses.

The script starts from:

``` text
intron_df_GC_GRCh38.rds
```

generated by `getIntrons_GRCh38_gtf.R`.

Introns are collapsed across transcripts based on unique genomic coordinates and strand. Only introns **≥30 nt** are retained.

The resulting introns are divided into:

``` text
Short introns: 30–100 nt
Long introns:  >100 nt
```

Both canonical and non-canonical splice-site introns are retained.

Major outputs include:

``` text
unique_intronPOS.rds
unique_intronPOS.csv
short_introns.bed
long_introns.bed
```

These intron sets are used for downstream analyses including:

1.  5′ and 3′ splice-site sequence logos
2.  splice-site strength analysis using MaxEntScan
3.  branch-point strength analysis using SVM-BPfinder
4.  CLIP-seq enrichment analysis

### `yeast_introns.R`

Generates intron annotations for:

-   *Saccharomyces cerevisiae*

The processed dataset contains:

``` text
species
seqnames
intron_start
intron_end
intron_length
intron_seqs
intron_GC
```

This dataset is subsequently combined with the plant and vertebrate intron datasets for the cross-species analysis shown in **Fig. 2A**.
